# Subtitle Translator

אפליקציית מק קטנה שיושבת בשורת התפריטים העליונה. היא מאזינה לתיקייה שבחרת, וכשמגיע אליה קובץ כתוביות באנגלית (`.srt`) היא מתרגמת אותו לעברית עם Claude ושומרת לידו קובץ `.he.srt`. בסוף מופיעה התראה, ולחיצה עליה פותחת את הקובץ ב-Finder.

## התקנה

1. מורידים את **SubtitleTranslator.zip** מ-[הגרסה האחרונה](../../releases/latest).
2. פותחים את ה-zip וגוררים את **Subtitle Translator** לתיקיית **Applications**.
3. בפתיחה הראשונה מק יציג אזהרה, כי האפליקציה לא חתומה אצל אפל. כדי לאשר:
   - לוחצים **Done** באזהרה.
   - פותחים **System Settings ← Privacy & Security**, גוללים למטה ולוחצים **Open Anyway** ליד Subtitle Translator.
4. מדביקים את מפתח ה-API של Anthropic. יוצרים אותו ב-[console.anthropic.com](https://console.anthropic.com/settings/keys), לוחצים Copy, ובאפליקציה לוחצים **הדבק מהלוח ושמור**.
5. מאשרים התראות ואת הגישה לתיקיית ההורדות כשמק שואל.

## מה יש בתפריט

- סטטוס, כולל אחוז התקדמות בזמן תרגום.
- בחירת תיקייה להאזנה. ברירת המחדל היא Downloads.
- תרגום ידני של קובץ אחד או כמה קבצים.
- בחירת מודל: Sonnet לאיכות גבוהה או Haiku למהירות ולחיסכון.
- תיקון פיסוק לנגנים ולטלוויזיות שמציגים נקודות וסימני שאלה בצד הלא נכון.
- הפעלה אוטומטית עם הדלקת המחשב.
- יציאה.

## הערות

- קבצים שכבר היו בתיקייה לפני שהיא נבחרה לא מתורגמים אוטומטית. בשבילם יש "תרגם קובץ עכשיו".
- קבצים שכבר בעברית, או שכבר יש להם קובץ `.he.srt`, מדולגים.
- המפתח נשמר רק על המחשב, בקובץ פרטי בתיקייה `~/Library/Application Support/SubtitleTranslator`.
- דורש macOS 13 ומעלה ועובד גם על מעבדי Apple וגם על מעבדי Intel.

## בנייה

כל דחיפה ל-`main` בונה את האפליקציה אוטומטית בשרת מק של GitHub (`build.sh`) ומפרסמת אותה כגרסה האחרונה.
